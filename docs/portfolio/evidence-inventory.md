## Publication rules

- `illustrative` means an independently reasoned reference model, not a shipped project.
- `reported` means supplied by the owner but not independently verified by a public artifact in this repository.
- `verified` requires a source artifact that supports the exact claim being published.
- `private-review` requires owner review before public wording; it is not a public case study.
- Missing metrics, testimonials, client names, customer counts, deployment status or outcomes remain missing; they must not be inferred from technology exposure.

## Current conclusion

Only the generalized order/inventory analysis is publication-ready as a substantive technical page. The other areas should remain qualified summaries until the owner supplies the specific artifacts listed above. The next safe product improvement is therefore an evidence-oriented index and clearer qualification labels, not a batch of invented case studies.
